# Pure Python Beginners

A collection of simple, pure Python scripts for newcomers. No external libraries needed.

## Scripts

- `temperature_converter.py` - converts Celsius to Fahrenheit
- `guess_number.py` - a number guessing game

## How to run

1. Install Python 3.
2. Run a script: `python temperature_converter.py`
